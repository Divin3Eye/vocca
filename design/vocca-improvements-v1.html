⚡ Steal-worthy features from the rivals

Sourced from Wispr Flow's changelog/features + Handy's open-source docs & GitHub discussions.

Transforms Wispr — PICK #1

Your 5 modes (Instant/Email/Chat/Note/Code) are already mini-transforms — the upgrade: re-run the shape on already-dictated text (select transcript → "as email" / "as code" / "replace"). Turns the mode row into a rewrite engine.

Re-insert last dictation (paste recovery) Handy — PICK #2

If a paste lost focus, press "re-insert last" (hotkey above) and Vocca puts your last dictation into the field you're now in. Handy users begged for this; it's table-stakes for a dictation app.

Live word count + WPM + pulse already have (v2)

Great — Wispr charges for half of this. Keep.

Per-language hotkeys Handy — PICK #3

Handy's #1 user request: separate shortcut for English vs Hindi so it never mixes. Our hotkey list makes this free: "Dictate" + "Dictate in Hindi".

Quit-mid-dictation recovery Wispr

If you close the tab mid-dictation, the audio is saved — reopen → History → Recover. Deal for the web app: keep the interim transcript in localStorage (never the audio).

Snooze / hands-free shake Wispr

Mobile-only for them — skip here, the floating bar + hotkey already covers hands-free on desktop.

Voice editing of selected text Wispr

Highlight text, say "make it more professional" — for Vocca this works fully inside the transcript area and History, not system-wide (web constraint). Feature it later — the app/#3 stage is where it becomes a desktop thing.
